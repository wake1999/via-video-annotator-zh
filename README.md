# VIA 视频标注器（中文本地化版）

[VGG Image Annotator (VIA)](https://www.robots.ox.ac.uk/~vgg/software/via/) 视频标注演示页面的简体中文汉化版本，基于上游 **VIA 3.0.13**，保留原有功能与单文件离线架构。

- 页面文件：[`index.html`](index.html)（约 4.3 MB，包含内嵌演示视频）
- 上游页面：<https://www.robots.ox.ac.uk/~vgg/software/via/demo/via_video_annotator.html>

## 功能

- **时间段标注**：为视频/音频添加、移动、合并、删除时间段，支持多轨道（多说话人）时间轴。
- **空间区域标注**：在暂停的视频帧或图像上绘制矩形、极端矩形、圆、椭圆、直线、多边形、折线、点等区域。
- **属性编辑器**：自定义属性名称、锚点、输入类型（文本、下拉、单选、复选）、选项与默认值。
- **项目操作**：打开/保存 VIA 项目，导入/导出标注（VIA3 CSV、时间段 CSV 等）。
- **键盘快捷键**与**快捷提示**页面已完整汉化。
- **离线可用**：整个应用是一个自包含 HTML 文件，无需安装或联网（演示视频已内嵌为 base64）。

## 使用方式

### 方式一：直接打开

下载或克隆本仓库后，用浏览器打开 `index.html` 即可。首次打开会显示“快速提示”，关闭后自动加载演示视频。

应用完全离线，直接用 `file://` 打开也正常（演示视频已内嵌）。

### 方式二：Windows 启动脚本（推荐）

双击 `start.bat`：

- 已安装 Python：自动在端口 8765 启动本地静态服务并打开浏览器；
- 未安装 Python：自动用默认浏览器打开 `index.html`。

关闭弹出的“VIA 本地服务器”窗口即可停止服务。

### 方式三：手动启动本地静态服务

```bash
python -m http.server 8765
# 浏览器访问 http://localhost:8765/index.html
```

## 汉化范围

- 顶部工具栏提示、形状选择与快捷键说明
- 时间段轨道、播放模式、时间轴增删界面
- 文件加载/错误提示、文件属性页
- 属性编辑器表头、锚点说明、按钮与输入提示
- 导入/导出、共享项目、关于页面
- 演示项目中的活动、阶段、目标等标注文本

## 与上游的差异

- 全部界面文本翻译为简体中文（键盘按键名称如 `Space`、`Ctrl` 保留英文）。
- 移除了原页面的 Google Analytics 统计代码，避免本地化部署的使用数据被计入上游项目统计。
- 未修改标注数据格式与导出逻辑，导出的项目文件与上游 VIA 兼容。
